Why this direction

  1. Driving-first contrast. Dark, low-glare surfaces with tabular numerals — legible at a glance, day or night.
  2. One primary action per screen. The route CTA dominates; everything else is subordinate.
  3. Severity is redundant, not colour-only. Every state pairs colour with a label (WCAG color-not-only).
  4. Government-grade web. Navy + blue reads institutional and prints/Embeds cleanly for DPWH reporting.
  5. Token-driven. One variable set drives both apps; a palette change lands everywhere at once.

Note: the skill's product-type query returned 0 matches for “maps/navigation utility”, so style/colour/type guidance was used directly (noted as a fallback, not a DB hit). Fonts load from Google Fonts; everything else is self-contained and works offline.
